# 幻覺掃描的「正常詞」白名單（誤報排除）。
#
# 用法：每行一個「完整的正常詞／片語」。掃描器截出的候選字串只要**出現位置**與
# 這裡任一片語的出現位置重疊，該次出現就不計為幻覺。寫完整片語（而不是寫候選字串
# 本身）是刻意的——這樣排除的理由看得見，也不會順手把別的字串一起放過。
#
# 加進來的門檻：必須先用 `--audit` 看過上下文，確認它在該語境裡真的不是名冊實體的訛寫。
